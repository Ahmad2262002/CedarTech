# Cedar Tech - Lebanon E-Commerce MVP

A premium e-commerce platform designed for a Lebanon-based electronics retailer selling smartphones, laptops, custom gaming PCs, and related tech gear. 

The site features a dark slate high-end aesthetic, fully responsive styling, local payment configuration (Cash on Delivery, Whish Money, OMT, bank transfers), a seamless popup-login checkout flow, and a comprehensive control panel dashboard for store administrators.

## Technical Architecture & Stack
- **Framework:** Next.js (App Router with nested layout route groups)
- **Language:** TypeScript
- **Database:** MongoDB via Mongoose ODM (featuring connection caching for hot-reloads)
- **Styling:** Tailwind CSS v4 (incorporating custom animations, gradients, and scrollbars)
- **Authentication:** Custom JWT stored in secure HTTP-only cookies, combined with server-side layout guards

---

## Folder Structure Overview
- `src/app/` - Page and API routing structure.
  - `src/app/layout.tsx` - App HTML boilerplate wrapped in context Providers.
  - `src/app/(storefront)/` - Public storefront route group. Contains Navbar, Footer, cart side drawer, and login popup modal.
  - `src/app/admin/` - Admin route directories.
    - `src/app/admin/login/` - Isolated portal login screen.
    - `src/app/admin/(dashboard)/` - Protected dashboard layout. Contains sidebar and nested views for Overview, Products, Categories, Orders, Customers, and Settings.
  - `src/app/api/` - API endpoints for auth (`login`, `register`, `logout`, `me`), `seed`, `settings`, `checkout`, and `admin` control.
- `src/components/` - Shared UI elements (Product Card, Navbar, Cart drawer, Modals, spec grids).
- `src/lib/` - MongoDB connector client, cryptographic JWT helper, and client React contexts (`CartContext`, `AuthContext`).
- `src/models/` - Mongoose database schemas (`User`, `Product`, `Category`, `Order`, `StoreSettings`).

## Local Setup Instructions

### Prerequisites
- Node.js (v18.x or higher)
- NPM package manager
- A local MongoDB instance running (e.g., `mongodb://localhost:27017/cedar_tech`) OR a MongoDB Atlas connection string.

### 1. Installation
Navigate into the project directory and install dependencies:
```bash
cd cedar-tech
npm install
```

### 2. Environment Configuration
Create a `.env.local` file in the root of the project (copying values from `.env.example`):
```env
MONGODB_URI=mongodb://localhost:27017/cedar_tech
JWT_SECRET=cedar_tech_super_secret_jwt_key_2026_lebanon_store
NEXT_PUBLIC_STORE_NAME="Cedar Tech"
```

### 3. Seeding the Database
To populate the database with categories (Phones, Laptops, Accessories, Gaming, Parts), high-quality sample electronics, store default configurations, and test user accounts, launch the application:
```bash
npm run dev
```
Then, simply visit the following URL in your web browser:
**[http://localhost:3000/api/seed](http://localhost:3000/api/seed)**

*This will wipe the selected database and write fresh clean seed data.*

### 4. Running the Development Server
Run the dev task to start the server:
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to view the storefront.

## Key Features Built

1. **Popup Login flow:** If an unauthenticated visitor clicks "Add to Cart" or "Proceed to Checkout", the system suspends the request, pops up the login modal, and upon successful authentication, immediately resumes the user's action.
2. **Lebanon Payment Forms:** The checkout page features Cash on Delivery in USD cash, alongside Whish Money / OMT local transfer inputs requiring sender reference code logging.
3. **WhatsApp Receipter:** Upon successful checkout, a confirmation receipt displays with a "Confirm via WhatsApp" button, letting clients share receipt metadata immediately to the store's WhatsApp number.
4. **Dynamic Specifications:** In the admin product manager, administrators can dynamically append custom key-value pairs (e.g., "GPU", "Processor", "VRAM") to individual products.
5. **Real-time Stats:** The admin home page displays active totals of inventory items, revenue aggregations, and stock alarm warnings.
